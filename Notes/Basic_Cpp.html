1. Basic Skeleton & Input/Output

Every C++ program shares a common foundational structure to handle inputs and outputs. You must include a library to enable specific functionalities.

  • #include <iostream>: Standard library for basic I/O.
  • #include <bits/stdc++.h>: The "master" header. Includes all standard libraries at once. Great for competitive programming.
  • using namespace std;: Prevents typing std:: repeatedly before basic commands.
#include <bits/stdc++.h>
using namespace std;

int main() {
    int x;
    // Input
    cin >> x; 
    
    // Output with line break (faster than endl)
    cout << "Value is: " << x << "\n"; 
    
    return 0;
}

2. Data Types

Integers

  • int: ~ -10^9 to 10^9
  • long: Wider range
  • long long: ~ -10^18 to 10^18 (Crucial for large inputs)

Decimals

  • float: Standard decimal
  • double: Wider range & higher precision

Strings & Characters

  • char: Single char in single quotes 'h'
  • string: Text in double quotes "hello"
Crucial String Input Note: cin >> s; only reads until the first space. To read an entire line including spaces, use getline(cin, s);

3. Conditional Logic

If / Else If / Else

Using else if prevents the program from checking subsequent conditions once a match is found, saving execution time compared to multiple standalone if blocks.

int age = 20;

if (age < 18) {
    cout << "Not an adult";
} else if (age >= 18 && age <= 60) {
    // Executes if the first condition is false AND this is true
    cout << "Adult";
} else {
    // Optional fallback
    cout << "Senior";
}

Switch Statement

Evaluates a variable against matching case blocks. You must include a break; statement, or "fall-through" will occur (executing all below cases).

int day = 2;
switch(day) {
    case 1:
        cout << "Monday";
        break; // Crucial!
    case 2:
        cout << "Tuesday";
        break;
    default: // Catches unmatched inputs
        cout << "Invalid Day";
}

4. Arrays & Strings

1D and 2D Arrays

Arrays hold collections of the exact same data type. They use 0-based indexing. Memory is allocated contiguously for elements.

// 1D Array of size 5
int arr[5]; 
cin >> arr[0]; // Access first element
arr[3] += 10;  // Modify 4th element

// 2D Array: 3 rows, 5 columns
int matrix[3][5]; 
matrix[1][2] = 78; // 2nd row, 3rd column

Strings as Arrays

Strings act as arrays of characters. You can access individual characters by index.

  • Access letter: s[0]
  • Find length: s.size() or s.length()
  • Last index: s.size() - 1

5. Loops

For Loop

Best used when you know exactly how many times to iterate.

// for(initialization; condition; increment/decrement)
for(int i = 1; i <= 10; i++) {
    cout << "Striver " << i << "\n";
}

While Loop

Runs continuously as long as condition is true. Checked before executing.

int i = 1;
while(i <= 5) {
    cout << i;
    i++;
}

Do-While Loop

Executes code block first, then checks condition. Guaranteed to run at least once.

int i = 2;
do {
    cout << "Executes once!";
    i++;
} while(i <= 1);

6. Functions

Functions make code modular, readable, and reusable. They handle specific tasks so you don't repeat code.

Void Functions

Performs an action but does not return a value.

void printName(string name) {
    cout << "Hey " << name << "\n";
}

int main() {
    printName("Raj"); // Function Call
    return 0;
}

Return Functions

Processes input and yields a specific data type back. Must hit a return statement.

int sum(int num1, int num2) {
    int res = num1 + num2;
    return res;
}

int main() {
    int answer = sum(5, 6);
    cout << answer; // Prints 11
    return 0;
}

7. Pass by Value vs. Pass by Reference

Crucial for Debugging

Understanding how parameters are passed to functions is one of the most common sources of errors in algorithms.

Pass by Value (Default)

Sends a copy of the variable. Changes inside the function do not affect the original variable in main().

void doSomething(int num) {
    num += 5; // Modifies the COPY
}

int main() {
    int x = 10;
    doSomething(x);
    cout << x; // STILL PRINTS 10!
    return 0;
}

Pass by Reference (&)

Sends the exact memory address. Changes inside the function directly alter the original variable.

void doSomething(int &num) { // Added &
    num += 5; // Modifies ORIGINAL
}

int main() {
    int x = 10;
    doSomething(x);
    cout << x; // NOW PRINTS 15!
    return 0;
}
The Array Exception:

Standard arrays are always passed by reference automatically. You do not need the & symbol; any modifications inside the function affect the original array.
